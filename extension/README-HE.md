# התוסף של Ranilix לכרום

לוחצים על התוסף בדף הרשמה של אתר כלשהו, ומקבלים:
- כתובת Ranilix חדשה רק לאתר הזה (למשל `netflix--k3x9qa@ranilix.com`). המיילים שלה מגיעים לתיבה הרגילה שלך.
- סיסמה חזקה. היא נשמרת רק במחשב הזה, בתוך התוסף, ולא נשלחת לשרת.
- כפתורי "העתק", כפתור "מלא בדף", וכפתור "בדוק מיילים" שמראה את קוד האימות שהאתר שלח.

## התקנה (פעם אחת)
1. פותחים בכרום את הכתובת `chrome://extensions`
2. מדליקים למעלה מימין את **מצב מפתח** (Developer mode)
3. לוחצים **טען תוסף לא ארוז** (Load unpacked) ובוחרים את התיקייה `D:\ranilix-email\extension`
4. לוחצים על סמל הפאזל ליד שורת הכתובת, ומצמידים את Ranilix
5. לוחצים על התוסף ומתחברים עם החשבון שלך ב-Ranilix

אחרי עדכון של הקבצים בתיקייה, לוחצים על החץ המעגלי של התוסף בדף `chrome://extensions`.
